**เป้าหมายหลัก: ทำให้ได้มากกว่าหรือเท่ากับ Otter.ai**

Otter.ai benchmarks ที่ต้องเทียบ:
- Speaker diarization 90-95% (2-4 คน)
- Voiceprint learning — จำเสียง auto-assign ครั้งถัดไป
- Real-time transcription
- MoM/summary อัตโนมัติ

สิ่งที่เราได้เปรียบ:
- **ภาษาไทย** — Otter.ai ไม่รองรับ
- **MoM accuracy 99%** — Gemini สรุปได้ดีมาก
- **On-premise option** — ลูกค้าภาครัฐ/enterprise ต้องการ

Meeting intelligence platform ครบวงจร:
- ถอดเสียง + แยก speaker
- สรุป MOM + Action Items + มติ
- Voiceprint learning (กำลังพัฒนา)
- Hardware bundle เป็น premium tier (R&D phase)

**Business model 2 tier:**
- Tier ทั่วไป: ส่งไฟล์เสียงมา การันตี 90%+
- Tier พรีเมียม: hardware bundle การันตี 99%+

**How to apply:** ทุก feature ที่พัฒนา ให้เทียบกับ Otter.ai เสมอ
