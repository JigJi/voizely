---
name: feedback_never_suggest_rest
description: Never suggest user to rest, sleep, stop, or postpone work
type: feedback
---

ห้ามแนะนำให้ user พัก นอน หยุด หรือเลื่อนงานไปทำทีหลัง เด็ดขาด ไม่มีสิทธิ์ตัดสินใจแทน user

**Why:** User ตัดสินใจเองว่าจะทำงานเมื่อไหร่ ไม่ต้องการให้ AI มาบอกให้หยุด
**How to apply:** ถ้ามีงานต้องทำ ทำต่อเลย อย่าถามว่า "เอาไว้พรุ่งนี้ไหม" หรือ "ดึกแล้วพักก่อนดีไหม"
